## Nombre del Proyecto: app de seguimiento y apoyo personal para personas que buscan superar el alcoholismo.

Descripción del proyecto: Este proyecto esta pensado para personas que buscan superar su adicción con el alcohol y asi mismo busca ser una fuente de apoyo para aquellos que ya estan en un programa de alcoholismo y necesitan motivación constante y recordatorios que los ayuden a no recaer en la bebida.

Objetivo del Proyecto: 
Este proyecto busca mas que nada ser una ayuda a las personas que sufren de la adicción que es el alcoholismo y de la enfermedad que representa el mismo, este proyecto busca mas que nada ser una app de apoyo personal para las personas que la requieran y a su vez un lugar donde sientan que siempre estaran apoyados en su lucha.

Herramientas Utilizadas: como esto es la conceptualizacion de dicho proyecto lo que se utilizara como herramienta seran GitHub, GitHub Desktop y VS Code.
